      BLUESKILLS design system

      One set of parts for the worker web app (phones first) and the organisation and admin workspaces. Every class here is a standard Tailwind utility using the token colour names, so it copies straight into React.

      All names, jobs and figures are sample data

      Rules for workers who read little

      Many workers read slowly or not at all. These six rules apply to every worker screen. Organisation screens can be denser, but they use the same parts.

      • Icon + word, always

        Every button and tab has a picture and a short word. No icon-only actions for workers.

      • One main action per screen

        One big blue button at the bottom. Everything else is quieter.

      • Listen and speak

        Key text has a Listen button. Long answers can be spoken instead of typed.

      • Big targets, big text

        Worker buttons are 48–56px tall. Body text is 16px or larger.

      • Colour is never alone

        Status = colour + icon + word, so it works for colour-blind users and in dark mode.

      • Plain, short words

        "You pay: Nothing", not "Zero recruitment-fee policy applies". Numbers before words.

      Colour tokens

      Same names in both themes. Use the name (bg-surface, text-muted), never a raw hex. Every text pairing below passes WCAG AA (4.5:1). linestrong is for form-control borders (3:1).

      Meaning

      • brand – main actions, links, selected state
      • stamp – progress in hiring (shortlist, interview), passport stamps
      • ok – a real check passed, money you don't pay, done
      • warn – under review, "Not disclosed", costs you pay
      • bad – errors, rejected, report a job, delete
      • muted – secondary text, worker-declared (unchecked) facts

      Typography

      Bricolage Grotesque for Latin headings, Figtree for text. Bangla, Devanagari and Urdu use Noto fonts with taller line height. Nothing is smaller than 13px; worker body text is 16–18px.

      Icons

      24px line icons, 2px stroke (Lucide style; use lucide-react in the app). Arrows and "back" mirror in Urdu (.flip-rtl). Trade icons sit on a soft tile.

        Segmented control

        Modal, bottom sheet, drawer, toast

        Built on the native <dialog> element, which handles focus, Esc and the backdrop. Use a modal to confirm. On phones, use a sheet for choices and filters (it becomes a centred dialog on wide screens). Use a drawer for navigation. Use a toast to confirm an action without blocking.
